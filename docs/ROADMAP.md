# CircuitNexus 开发路线图

| 阶段 | 重点 | 可验收交付 |
|---|---|---|
| P1 能力验证 | 网表解析、原理分析、原理图评审、简易原理图生成 | 真实测试集上的端到端 Demo 与错误记录 |
| P2 架构工程化 | Harness/Skill/MCP/知识库边界，规则引擎，回归测试 | 接口规范、插件适配、自动测试 |
| P3 品牌与客户端 | CircuitNexus Logo、双主题、PCB 纹理、侧栏入口、安装包 | 可启动可卸载的品牌 Windows Desktop |
| P4 集成与测试 | 真实工程集成、依赖打包、权限、离线/更新/安全 | 无开发依赖的安装测试和性能报告 |
| P5 正式发布 | Landing Page、文档、教程、示例工程、下载与反馈 | 稳定发行包、官网与版本维护机制 |

## 当前优先级
**先做 P1 能力证据 + P3 品牌样机的最小交集**，再加大功能范围；不要同时推进完整 PCB 自动布线、复杂 SI/PI 仿真和企业多租户平台。

### 建议首轮里程碑
- 公开设计仓库形成品牌/素材/规范单一来源；
- Windows 上能看到 CircuitNexus 品牌首页；
- 两主题切换无闪屏、无可读性回退；
- 原理图评审流程至少可对一个完整样例解析、输出报告并校验；
- 首次安装、升级、故障恢复通过测试。

### 度量与退出门槛
每阶段都需要：可复现样例、测试结果、失败清单、可交付物清单和人工确认点。

# CircuitNexus Light｜暖白香槟金主题 V1.0

> 定位：温润工程纸张 + 香槟金电路线条，保持专业与高可读性。**亮色不是暗色简单反相。**

## 对比度硬约束
- `#C79A3B` 在 `#FBF7EF` 上的普通文字仅约 **2.42:1**，**禁止**作为小字号文本；
- 暖白底的金色小字使用 `#805C1E`，约 **5.67:1**；
- 香槟金实心按钮使用深色 `#221B12` 字，不用白字；
- 一般文本目标 ≥4.5:1，重要图形与大字目标 ≥3:1；混合透明色需要重算最终复合色。

## 组件指导
- 侧栏与主画布有柔和色阶；输入框固定白色，优先体现可输入性。
- 一级导航选中底色 `#EFE0C5`，不是深金大色块。
- 浮层/弹窗用低饱和阴影 + 暖色边线，不做黄色泛光。
- 金色只负责 CTA 和少量活跃提示；错误/警告另有语义色。
- 状态：通过 `#166B4F`、警告 `#8B5C17`、错误 `#AC3333`、信息 `#225DA9`。

## PCB 矢量纹理
- 欢迎页完整背景：[`circuitnexus-pcb-light-welcome.svg`](../assets/themes/pcb/circuitnexus-pcb-light-welcome.svg)
- 透明叠层：[`circuitnexus-pcb-light-overlay.svg`](../assets/themes/pcb/circuitnexus-pcb-light-overlay.svg)
- 四角香槟金走线、中央大留白；点阵尽可能淡。
- 欢迎页低对比纹理；进入对话/工程报告页后降至约 6% 或直接移除。
- 不允许纹理穿过输入文字、代码和评审结果表格。

## 禁止
禁止大面积高饱和亮金、背景与侧栏全同色、低对比金色小字、在白色卡片上叠加浓密 PCB 网格、重投影。

## 验收
- 首页、侧栏、输入、设置、长文、表格、弹窗逐页截图；
- 所有金色文本按语义与对比度选择，长会话可读；
- 100/125/150% 缩放验证，浅金纹理不造成视觉干扰。

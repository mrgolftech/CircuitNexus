# CircuitNexus Dark｜石墨黑金主题 V1.0

> 定位：沉金焊盘 + 黑色阻焊板的工程专业感。**暗色是信息承载，金色是少量焦点。**

## 颜色基线
| 语义 | Hex | 设计意图 |
|---|---|---|
| 主画布 Canvas | `#0D0E10` | 深石墨黑，降低长期使用视觉疲劳 |
| 侧栏 Sidebar | `#16181D` | 与主画布形成轻微层级 |
| 顶栏 Topbar | `#111216` | 避免突兀分界 |
| 普通容器 Surface | `#1D2025` | 中性承载 |
| 卡片 / 输入框 | `#23262C` | 明确可交互层级 |
| Hover | `#2B2D33` | 轻微亮度提升 |
| Active | `#3A3020` | 低饱和的选中底色 |
| Border | `#3C3D42` | 普通线框 |
| Divider | `#34353A` | 弱分割 |
| 主字 | `#F2F4F7` | 长文本清晰 |
| 次字 | `#9AA0A6` | 辅助说明 |
| 品牌强调 | `#D4AF37` | 主操作/选中标记/Logo |
| Focus | `#E8C875` | 高可见键盘焦点 |
| PCB 走线 | `#3A3124` | 低对比纹理 |
| 点阵 | `#877051` | 少量工程底纹 |

## 组件指导
- 侧栏：246px 参考宽度，折叠为 64px。默认灰白图标，选中条目才用暗金底。
- 输入框：独立于主画布的 `#23262C`，边框 `#3C3D42`；没有必要的发光。
- 主按钮：`#D4AF37` 背景 + `#221B12` 字；每屏原则上一个。
- 卡片：`#1D2025` / `#23262C`，轻边框，不要黄色厚描边。
- 状态：通过 `#5BC7A0`、警告 `#E9B765`、错误 `#F28B86`、信息 `#79A9F5`。
- 正文字号 14–16px，辅助字号 12–13px；较长工程报告禁用装饰背景。

## PCB 矢量纹理
- 欢迎页完整背景：[`circuitnexus-pcb-dark-welcome.svg`](../assets/themes/pcb/circuitnexus-pcb-dark-welcome.svg)
- 透明叠层：[`circuitnexus-pcb-dark-overlay.svg`](../assets/themes/pcb/circuitnexus-pcb-dark-overlay.svg)
- 欢迎页四角低对比连续走线，中央留白以突出主标题和输入框；点阵 28–32px 间距。
- 正文页纹理建议降低到 4% 或直接隐藏；不得经过大段文字、网表表格或代码框。
- 采用 SVG 矢量元素和简单几何，不嵌入位图；不使用不停流动的金色粒子动画。

## 禁止
禁止满屏金色、高饱和金色大面积填充、发光描边包围每个组件、背景遮挡内容、低对比暗灰正文。背景不可拦截点击操作。

## 验收
- 金色主按钮/正文/次文字与背景对比度符合 UI 规范；
- 100/125/150% Windows 缩放均清晰；16px 图标不糊/不粘连；
- 首页/聊天/设置/报告/代码/表格各截屏；不引入主题切换闪屏；
- 长文本不出现装饰干扰与错误状态色混用。

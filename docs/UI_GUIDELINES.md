# CircuitNexus（电路智枢）双主题视觉设计规范 V1.0

**设计基线：** 用户现有 HardBuddy 深色/浅色桌面截图（1536×864）；在基本保持布局和黑金气质的前提下，统一颜色语义与可读性。
**产品定位：** AI 硬件研发工作台；品牌风格为 Precision Black & Gold（精密黑金）。

## 1. 视觉设计原则

1. **黑色承载、金色聚焦**：黑、灰、暖白负责信息密度，金色只承担品牌及关键交互。
2. **借鉴实物黑色沉金 PCB**：黑色阻焊层、沉金焊盘、低对比度布线与丝印；不要模仿炫目的灯带或霓虹 PCB。
3. **亮色不是暗色反相**：采用暖纸白和米金；输入框与工作卡片白色，形成清晰层次。
4. **工程任务优先**：原理图、网表、代码、报告、对话的阅读性高于背景装饰。
5. **主题仅改变外观，不改变语义**：选中、确认、警告、错误在两个主题下的含义始终一致。

## 3. 交互与语义用色

| 状态 | Dark | Light | 行为约束 |
|---|---|---|---|
| 主要 CTA | 金色填充 `brand` + 深色字 `on-brand` | 同左 | 每个视图原则上只有 1 个主要实心金色动作 |
| 次级动作 | 中性容器 + 中性边框 + 主文字 | 白色/暖白容器 + 描边 | 不与主 CTA 竞争 |
| 导航选中 | 暗金半透明感 `selection-bg` | 浅香槟金 `selection-bg` | 保持图标与文字同时变化 |
| Hover | `hover` | `hover` | 避免所有 hover 都变成金色 |
| Focus | 2px `focus`，外偏移 2px | 同左 | 明确高对比焦点，不只依靠发光阴影 |
| 禁用 | `text-disabled`，弱化对比 | 同左 | 禁用状态必须有 disabled 语义与不响应行为 |
| 成功 | `success` + 对勾 | 同左 | 不与品牌色混用 |
| 警告 | `warning` + 警告图标 | 同左 | 警告不能只使用金色，必须配图标/文案 |
| 错误 | `error` + 纠错动作 | 同左 | 文字、边框及图标同步指示 |

## 4. 已核算的关键 WCAG 对比度

文字正常字号建议 ≥ 4.5:1；大字和必要的控件图形边界建议 ≥ 3:1。此处按 sRGB 的 WCAG 2.x 对比度算法计算，混合透明背景应以最终合成颜色再核算。

| 对比组合 | 对比度 | 判断 |
|---|---:|---|
| 暗色主文字 / 主画布 | **17.53:1** | 满足 4.5:1 |
| 暗色次文字 / 输入框 | **5.74:1** | 满足 4.5:1 |
| 暗色金色文字 / 主画布 | **9.18:1** | 满足 4.5:1 |
| 亮色主文字 / 主画布 | **12.28:1** | 满足 4.5:1 |
| 亮色次文字 / 侧栏 | **4.70:1** | 满足 4.5:1 |
| 亮色金色文本专用 / 主画布 | **5.67:1** | 满足 4.5:1 |
| 亮色金色实心按钮深字 | **6.58:1** | 满足 4.5:1 |
| 暗色金色实心按钮深字 | **8.10:1** | 满足 4.5:1 |

**必须避免的三种情况：** ①直接用亮色品牌金 `#C79A3B` 写在暖白背景上，仅 **2.42:1**；②在亮色金色按钮上用白字，仅 **2.59:1**；③截图中亮色次文字 `#7A6F5E` 放在米色侧栏，仅 **4.10:1**，略低于普通文本 4.5:1 门槛。

## 5. 组件约束（桌面 1536×864 参考，需响应式）

- **布局**：侧栏基础宽度 246px（折叠 64px），顶部栏约 42px；工作区顶部不因侧栏而改变阅读中心。大视口保持输入区最大宽度 1000px，小视口随容器收缩。
- **间距**：基础单位 4px；常用间距 8/12/16/24/32；页面安全边距 24px，密集表格可以 12/16px。
- **圆角**：小按钮 8px、导航 10px、卡片 14px、主页多行输入容器 22px。避免所有容器过度圆角。
- **文字**：正文默认 14px，较长阅读区可 15–16px；辅助信息 12–13px；页标题 22–26px；行高 1.45–1.6；数字/标号使用等宽或 tabular numerals。
- **字体**：Windows 中文优先 `Microsoft YaHei UI` / `Microsoft YaHei`，英文 `Segoe UI`；其他平台采用系统 sans-serif。打包时勿直接分发未经许可的商业字体。
- **侧栏**：功能分组明确；一级导航命中区 ≥ 40px 高，图标 18–20px；被选中条目使用淡金背景，不要所有常驻条目都有金色描边。
- **输入框**：用户输入、模型选择、附件功能必须有清晰视觉分组。输入内容采用主文本色，Placeholder 使用可读的次文本色。暗色输入区与画布要有明显亮度差。
- **卡片/浮层**：正常底色保持低对比，浮层增加少量描边/投影，不用大范围金色投影；不要在任务执行页常驻色卡说明浮窗（目前截图右下角为设计说明，应仅保留在开发/设置页）。
- **点击与键盘**：交互目标建议 40×40px 以上；键盘 focus-visible 应有 ≥ 2px 可见外框，不能仅依赖悬停；支持高对比模式与系统减少动态效果。

## 6. PCB 背景装饰约束

1. 欢迎页允许四角/边沿点缀，正文、输入框、表格下方不能穿过导线。图形主要放在四角和边缘，中央阅读区域保持留白。
2. 背景 SVG 应采用简单连续的 45°/90° 走线、圆形过孔、极少量焊盘。避免真实元器件符号混进背景（可能误认为可编辑原理图）；走线分叉与过孔连接须自洽。
3. 建议线宽 1–1.5px；一组主线路 2–3 条以内；点阵间距 28–32px。禁止宽面积、强荧光发光、频繁动态流光。
4. Dark 欢迎页纹理建议透明度约 18%，点阵约 4.5%；Light 欢迎页浅金实体线本身很浅，可设约 45%，点阵约 6.5%，需以实际显示器检查。
5. 会话展开、代码显示、评审结果页应自动降到暗色 4% / 亮色 6% 或完全隐藏；SVG 背景应 `pointer-events:none`，不能拦截鼠标与复制选区。
6. 不能把背景线条作为状态或进度提示；所有真正信息必须在前景控件中表示。

## 7. 品牌 Logo 约束（供后续重新设计）

- 完全停用 HardBuddy 的 H 芯片母题；优先探索 **C（Circuit）+ Node（连接）+ 芯片/电路路径的负形**，而不是又画一个复杂彩色芯片图标。
- Logo 默认以**单色沉金**搭配暗底，亮色以深棕黑图形为主，可少量金色点缀；不要电蓝/青绿渐变。
- 64px、32px、16px 三种尺寸仍能辨认；小尺寸删除细走线与装饰光圈。最小金属笔画不低于基准笔画 1/4。
- 为图标、横排品牌字、纯黑白、金/黑、金/浅底分别提供独立版本。品牌图案不能直接取用他人的商标形状。

## 8. 实现与验收

- Token 放入 `circuitnexus-theme-tokens.json` / `circuitnexus-theme-tokens.css`，由 HardBuddy/ CircuitNexus 主题插件映射至实际 DSH Client 主题接口。文件只是语义层，不保证直接被 DSH 识别。
- 先完成首页、侧栏、输入框、模型切换、设置页面、聊天内容、表格、代码块的双主题截图比对。
- 自动检查关键文字对比度，亮色金色小字必须使用 `brand-text` 而不是 `brand`。
- 重点人工观察：125% / 150% Windows 缩放、1440p/1080p 屏幕、深浅切换闪烁、系统高对比模式、窗口窄屏。
- 状态色须同时结合图标与文字表达；长文本区必须具有稳定的文字对比度；工具结果表格/原理图截图绝不能被主题背景色改变其技术语义。

# CircuitNexus 电路智枢｜产品目标与范围

> 版本：V1.0（2026-11-12）｜定位：AI Hardware Engineering Workspace

## 1. 产品定位
CircuitNexus 是面向专业硬件工程师的 **AI 原生研发工作台**，基于开源 DeepSeek Harness 进行可维护的产品化扩展，融合大模型、Skill、MCP/CLI、EDA 软件、硬件知识库与可验证规则程序。

**产品评价标准不是能回答多少问题，而是能独立完成多少真实、可复核、可交付的工程任务。**

### 核心闭环
```text
设计需求/资料 → Agent 任务规划 → Skill 工程流程 → MCP/CLI/EDA 工具
              → 结构化工程结果 → 规则验证/人工确认 → 交付与追踪
```

## 2. 用户
- 专业硬件工程师、硬件研发团队、设计评审人员与电子技术研究人员；
- 首发优先 Windows Desktop，后续考虑 Linux 与企业 Web；
- 支持私有化、可控数据访问与可选云端/本地模型。

## 3. 功能边界（均为产品目标，除非单独标记验收，不视为已实现）
| 能力 | 输入 | 主要产物 | 自动验收方向 |
|---|---|---|---|
| 原理图设计 | 需求、数据手册、参考设计 | 可编辑原理图、BOM、设计说明 | ERC、网表、器件引脚映射 |
| 原理分析 | 原理图/网表/PDF | 模块、链路、工作机理说明 | 证据链接与连接一致性 |
| 网表解析 | OrCAD PST / XML / KiCad | 器件/引脚/网络拓扑 | 解析覆盖率与对照样本 |
| 智能原理图评审 | 网表、规范、器件手册 | 风险项、证据、整改建议 | 误报/漏报/规则覆盖率 |
| 电源树分析 | 电源网络、器件数据 | 电源树、负载表、时序检查 | 电源/负载可追溯 |
| PCB 与高速设计辅助 | PCB、叠层、接口约束 | SI/PI/EMC 布局布线建议 | 专业工具/规则校核 |
| 器件选型比较 | 需求、数据手册、BOM | 参数对比与替换评估 | 引脚、电压、时序逐项验证 |
| 工程交付 | 过程数据、检查结果 | 报告与验证记录 | 可复现执行与版本追踪 |

## 4. 分层架构
1. **Agent 层**：任务理解、规划、工具调用、上下文、结果检查；
2. **Skill 层**：按硬件任务维护工程方法、脚本、参考知识；
3. **工具层**：网表解析/规则引擎、KiCad、EDA CLI、MCP、Python；
4. **知识层**：资料索引、设计规范、评审规则、器件手册、案例；
5. **交互层**：桌面工作台、专业任务入口、报告和工程文件；
6. **验收层**：可复现测试集、规则回归、报告审计与人工确认点。

## 5. 工程原则
- **确定性优先**：连通性、参数比较、ERC/DRC、格式转换等交专业工具；Agent 负责协调和解释。
- **结果可追溯**：每个工程判断最好指向元器件/引脚/网络/原始资料/规则编号。
- **可插拔与低侵入**：品牌层、主题、Skill、工具包保持独立于上游核心，降低 DSH 升级成本。
- **可恢复**：插件崩溃安全模式、超时和重试、隔离工作目录、更新回滚。
- **权限与数据隔离**：工具只获得最小必要权限；敏感网表/文档/密钥不提交公共仓库。
- **不夸大成熟度**：明确“构想 / Demo / 实验验证 / 测试通过 / 发布”。

## 6. V0.1 最小可交付
- Windows 安装后可见 CircuitNexus 品牌与两套主题；
- 内置至少三个硬件任务 Skill，启动自动注册；
- 至少一条 OrCAD/KiCad 网表解析到检查报告的真实闭环；
- 本地规则检查和 Agent 分析结果分层展示；
- 最小数据集自动回归，提供首装、升级与恢复测试记录。

## 7. 非目标
- V0.1 不宣称自动生成可投产 PCB、无需人工审核的安全关键设计；
- 不将模型文字推断当成电气验证；
- 不在公开仓库存放企业规范全文、私有手册、客户工程、生产数据或凭据。

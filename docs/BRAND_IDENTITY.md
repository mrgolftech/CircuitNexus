# CircuitNexus｜品牌识别规范 V1.0

## 1. 已定稿身份
- 英文：**CircuitNexus**（保持单词首字母 C、N 大写）；
- 中文：**电路智枢**；
- 定位：**AI 硬件研发工作台** / **AI Hardware Engineering Workspace**；
- 视觉定位：**Precision Black & Gold｜精密黑金**；
- 气质关键词：精密、沉稳、科技、克制、工程可信、可验证。

已弃用名称 HardBuddy。历史设计板中出现的 HardBuddy / “H 芯片”仅是设计演进记录，**不得在新发布件出现**。

## 2. Logo 构成
1. 开放式六边几何 **C** 轮廓象征 Circuit；
2. C 内部 **三条独立、等宽** PCB 信号走线；
3. 走线每一段为水平或 ±45° 直线，转角的较大夹角为 **135°**；
4. 右侧 **三个圆环状焊盘**，象征器件、连接与工具协同；
5. 锁定排布：左图形、纵向分割线、右侧英文 CircuitNexus、下方中文 电路智枢。

**结构优先级：** 几何比例与三走线逻辑 > 金属材质渲染。SVG 是可编辑的结构母版，不从截图像素追踪。大型 Hero 可使用有限金属渐变；16–32px 小图标使用纯色/简化版。

### 必须保持
- 三走线等宽，不出现局部粗细变化或锥形端部；
- 转角不使用圆弧/任意倾角，内线不出现 90° 急转；
- 三个焊盘独立可辨，图形在 24px 开始测试；
- 不改变 C 与内部线条相对角度、端点顺序和 C 开口方向。

### 不得使用
蓝绿渐变旧版、H 芯片标志、满屏金色发光、过于精细以致缩小时粘连的叠层装饰。

品牌金不是工程警告色；功率风险、器件不匹配、故障报告要使用明确语义色和图标。

## 5. 字体
- 客户端正文：Windows 中文优先微软雅黑 UI；英文优先 Segoe UI，其他平台用系统 Sans。
- 网站品牌：可选择 Inter/思源黑体或系统字体；SVG 正式锁定字标已经转为路径，不能另行拉伸字形。
- SVG 资产不包含字体文件；如需独立分发字体，按许可审查。

## 6. 应用规则
- **导航栏**：横排 Logo，不加“powered by”到品牌主体；
- **桌面应用 / 任务栏**：统一黑金主图标，不因主题切换改变任务栏标识；
- **安装器**：主图形或完整 Logo，避免强金渐变造成缩放失真；
- **网页 Favicon**：使用简化图形，不加中文副标题；
- **背景纹理**：只能作为低对比装饰，不能抢走 Logo/CTA 的信息权重。

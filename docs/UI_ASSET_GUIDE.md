# UI 实现与视觉交付准则｜CircuitNexus V1.0

本文件配合 [完整 UI 设计规范](UI_GUIDELINES.md)、[暗色主题](THEME_DARK.md) 与 [亮色主题](THEME_LIGHT.md) 使用。

## 1. 版面布局（承接已有 Desktop UI）
- 顶部为应用菜单栏；左侧为工作台导航和工作区列表，右侧主内容区；
- 侧栏参考宽度 **246px**，折叠宽度 **64px**；顶部栏参考 **42px**；
- 首页中间显示品牌引导语、任务上下文与多行输入区；输入区最大宽度 **1000px**；
- 设计模式入口：原理图评审、原理图设计、更多硬件工具，作为应用模块而非品牌标志；
- 浮动色卡只用于设计调试页，**正式用户首页不显示**。

## 2. 颜色分层
```
背景 Canvas → 一级容器 Surface → 可操作容器 Raised → Hover/Focus → Semantic Feedback
```
禁止所有交互层同时采用金色描边；文本层级由主文本/次文本区分。

## 3. 组件与尺寸基线
| 类别 | 建议 |
|---|---|
| 4px 基础栅格 | 常用间距 8 / 12 / 16 / 24 / 32px |
| 圆角 | 8 / 10 / 14 / 22px（小控件 / 导航 / 卡片 / 主输入区） |
| 正文 | 14px，阅读密集内容 15–16px |
| 次要说明 | 12–13px |
| 页面标题 | 22–26px |
| 导航触达 | 建议 ≥40px 高 |
| 焦点 | 至少 2px 可见外框，外偏移 2px |
| 每屏主要 CTA | 原则上 1 个金色实心主操作 |

## 4. 背景装饰
- 仅欢迎页显示四角电路走线及浅点阵，中心留白；
- 正文/代码/网表/评审报告页背景纹理降至极低或隐藏；
- SVG 仅作为背景（`pointer-events: none`），不能覆盖控件；
- 不使用假器件、复杂网格或霓虹流光，也不通过纹理承载状态信息；
- `background-size: cover` 会裁切边缘，必须在 16:9、16:10、窄窗口测试；如追求完整图形可采用 `contain` + 独立背景色。

## 5. 可访问性
- 正文对比度 ≥ 4.5:1；大字/非文字组件关键边界 ≥3:1；
- 不仅依靠颜色区分“警告、失败、检查通过”，必须配图标和文字；
- 系统减少动态效果选项下禁用金色微动和高光动画；
- Tab 焦点、键盘快捷键、窗口缩放及系统高对比模式须测试。

## 6. 品牌与代码解耦
请在 DSH Fork 中将 theme tokens 单独映射至现有主题 API；不要用硬编码文本替换全部官方 UI。主题切换应即时、可恢复；插件启动失败要有 Safe Mode 回退。

详细验收表可从 [开发进度](STATUS.md) 展开。
